# Child-Sponsorship-Platform
## Contribution Guidelines
To contribute:
1. Create a new branch. If it's a feature, name the branch `feature/abcd` where `abcd` is the name of the feature you're working on. If it's a bugfix, name the branch `bugfix/abcd`. Not that serious, but being consistent will save us a lot of pain along the way.
2. Create a Pull Request (PR) to merge your branch to the `development` branch. The repository admin will then review your code and accept your PR or ask for further changes/adjustments. The repository admin will eventually push the `development` branch to main, where the platform lives.
